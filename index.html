              Chapter 01 — The beginning
              
My journey into cybersecurity began in the sixth standard — with a mobile phone, later a tablet, Linux tools and Termux.

              
No sophisticated computers, no expensive equipment, no professional lab. What began as curiosity about hacking became an obsession with understanding how technology works, how systems fail and how vulnerabilities are discovered. I explored Linux, security tools, phishing concepts, spoofing and the fundamentals of offensive security — through experimentation, research, and a lot of trial and error.

            


            

              Chapter 02 — From experimenting to engineering
              
That curiosity became a career.

              
I expanded into vulnerability assessment and penetration testing, web application security, authentication and authorization flaws, SQL injection, information disclosure and infrastructure security — and later AI application security, including prompt injection. Some investigations involved complex vulnerability chains, where multiple weaknesses combine into far greater impact. My approach: find the root cause, establish impact within authorized boundaries, and communicate findings responsibly.

            


            

              Chapter 03 — Building and breaking
              
Security is only one side of the story.

              
I'm also a full-stack and AI engineer who enjoys building things, not just testing them. Understanding how a system is designed helps me see how it might fail; understanding how it fails helps me build better systems. Today I work in AI security at EY, bringing these two sides together.
